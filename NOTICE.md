# Project and external components

Task Recursive Tree is published by **zwdmw** under the MIT license in [LICENSE](LICENSE). It provides the task-tree core, a deterministic planar reference backend and adapters for a separately installed GeminiER2Harness environment.

The included demo recording shows the GeminiER2Harness integration with MuJoCo. GeminiER2Harness, MuJoCo, model services, Faster-Whisper, OpenCC and downloaded model weights are external components. Their licenses and service terms apply to their own code, assets and use. Configuration for external services belongs in the external environment.

The MP4 was supplied for this project's public demonstration. Its original file identity and encoding information are recorded in [video metadata](docs/media/video.json). Screenshots and the GIF preview are derived from that recording.
